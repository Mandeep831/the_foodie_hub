# FoodieHub Style Guide

## Colour Palette

FoodieHub uses a simple green-based colour palette to create a clean and food-focused appearance.

| Colour Name | Hex Value | Usage |
|-------------|-----------|-------|
| Primary Green | `#2E7D32` | Header, headings, buttons, and recipe titles |
| Dark Green | `#256628` | Button hover effects |
| Light Gray | `#F5F5F5` | Main page background and review backgrounds |
| Dark Gray | `#212121` | Body text and footer background |
| White | `#FFFFFF` | Header text, button text, recipe cards, and ingredient cards |

## Typography

The application uses **Arial**, a sans-serif font, throughout the interface.

| Text Type | Font | Size |
|-----------|------|------|
| Main Header | Arial, sans-serif | `2rem` / 32px |
| Section Headings | Arial, sans-serif | Default browser heading size |
| Recipe Titles | Arial, sans-serif | `1.2rem` / 19.2px |
| Recipe Detail Headings | Arial, sans-serif | `1.1rem` / 17.6px |
| Body Text | Arial, sans-serif | Default 16px |
| Buttons | Arial, sans-serif | `0.95rem` / 15.2px |
| Recipe Images and Ingredient Images | Arial, sans-serif | `2.5rem` / 40px |

## Layout and Spacing

- The main content has a maximum width of `1150px`.
- The main page uses `20px` horizontal padding.
- Recipe, ingredient, and review cards use a three-column grid on larger screens.
- Cards have `20px` padding and a `10px` border radius.
- Cards use a light shadow to separate them from the background.
- The layout changes to two columns below `900px`.
- The layout changes to one column below `600px`.

## Components

### Header

- Background colour: `#2E7D32`
- Text colour: `#FFFFFF`
- Text alignment: centered
- Padding: `24px`

### Buttons

- Background colour: `#2E7D32`
- Text colour: `#FFFFFF`
- Border radius: `5px`
- Padding: `10px 14px`
- Hover background colour: `#256628`

### Cards

Recipe, ingredient, and review cards use:

- White background: `#FFFFFF`
- Border radius: `10px`
- Padding: `20px`
- Light box shadow
- Consistent spacing between cards

### Footer

- Background colour: `#212121`
- Text colour: `#FFFFFF`
- Centered text
- Padding: `20px`
