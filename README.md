## Project Description

FoodieHub is a web application where users can explore recipes, view the ingredients used in each recipe, and share reviews and ratings. Recipes may be created by users or administrators.

## High-Level User Stories

- As a user, I want to explore recipes so that I can find meals I would like to prepare.
- As a user, I want to view the ingredients for a recipe so that I know what I need to prepare it and make it more delicious.
- As a user, I want to write reviews and ratings so that I can share my experience with other users.
